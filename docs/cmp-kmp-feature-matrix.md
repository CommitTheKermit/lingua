# Flutter, Android 프로토타입, CMP/KMP 기능 대조표

## 기준

- Flutter는 복사 대상이 아니라 기존 동작을 확인하는 기준으로 사용한다.
- Android 프로토타입 회수본은 `recovery/android-prototype` 브랜치다.
- CMP/KMP 리더는 로그인 없이 TXT 문서를 열고 모든 읽기 상태를 공통 문장 인덱스로 관리한다.
- 사전의 목표 구조와 검증 기준은 `docs/cmp-kmp-dictionary-plan.md`를 따른다.

## 대조표

| 기능 | Flutter | Android 프로토타입 | CMP/KMP 분류 | 비고 |
| --- | --- | --- | --- | --- |
| TXT 문서 선택과 읽기 | 파일 선택기 사용 | Android SAF 사용 | 플랫폼 코드로 이식 | Android와 iOS의 시스템 문서 선택기를 각각 사용 |
| 문장 정규화와 분리 | 구현됨 | `SentenceSplitter`와 테스트 회수 | commonMain으로 이식 | 종결 부호 없는 마지막 문장을 보존하도록 보완 |
| 이전과 다음 문장 이동 | 구현됨 | 범위 제한과 상태 테스트 회수 | commonMain으로 이식 | 불변 상태와 문장 인덱스를 공유 |
| 읽기 위치 복원 | SharedPreferences 사용 | DataStore 구현과 테스트 회수 | 구현 완료 | `reader.db`에 마지막 문장 인덱스를 저장하고 공통 상태로 자동 재개 |
| 문장별 사용자 입력 복원 | JSON 파일 사용 | 문서 URI와 문장 인덱스로 저장 | 구현 완료 | 문서 ID와 문장 인덱스로 자동 저장해 동일 문장 반복도 구분 |
| 문서 검색 | 구현됨 | `DocumentSearch`와 검색 UI 회수 | 구현 완료 | commonMain 검색 결과가 문장 인덱스를 반환하고 같은 인덱스로 이동 |
| 줄 바로 이동 | 구현됨 | 검증 함수와 UI 테스트 회수 | 구현 완료 | 검색, 전체 보기와 북마크가 공통 `moveTo` 계약을 사용 |
| 원문, 번역, 입력 영역 표시 | 구현됨 | 설정과 저장 구현 회수 | 구현 완료 | 원문, 기계 번역, 사용자 번역과 전체 뷰어별 표시 설정을 공통 상태로 저장 |
| CSV 기록 추출 | 구현됨 | escaping 로직과 SAF 저장 구현 회수 | 구현 완료 | CSV 생성은 공통, 저장 위치 선택만 플랫폼 코드 |
| 드로어 메뉴 | 구현됨 | 전체 메뉴 UI 회수 | UI 결정 필요 | 모바일 드로어를 태블릿에도 그대로 적용하지 않음 |
| 뷰어 모드 | 구현됨 | 문장 단위 pager 회수 | 구현 완료 | 전체 문장을 문장 인덱스 순서로 스크롤하고 선택 시 같은 인덱스로 이동 |
| 북마크 | 구현됨 | 문서별 인덱스 저장과 UI 회수 | 구현 완료 | 문서 ID와 문장 인덱스로 `reader.db`에 저장 |
| 오프라인 영한 사전 | 서버 호출 중심 | 위키낱말사전 SQLite와 생성기 회수 | 플랫폼 코드로 이식 | 공통 UI와 상태, 플랫폼 SQLite 드라이버 사용 |
| 사전 활용형 조회 | 없음 | DB 생성 시 lookup 키로 검증 | commonMain으로 이식 | 런타임 형태소 분석은 추가하지 않음 |
| 사전 누락 DeepL 보완 | 구현됨 | `translateProxy` 호출 구현 | UI 결정 필요 | 기존 백엔드는 인증 필수라 로그인 없는 계약으로 수정 필요 |
| 로그인, 회원가입, 계정 복구 | 구현됨 | 익명 인증과 Firebase Auth 코드 존재 | 의도적으로 제외 | 앱은 로그인 없이 사용 가능해야 함 |
| 사용자별 번역 quota 표시 | 구현됨 | Firestore 기반 구현 존재 | 의도적으로 제외 | 로그인 제거로 사용자별 quota 계약을 사용하지 않음 |
| Firebase App Check | 일부 구현 | debug와 release 공급자 회수 | 플랫폼 코드로 이식 | 온라인 번역을 다시 연결할 때만 도입 |

## 이식 우선순위

1. `SentenceSplitter`, 문장 인덱스 이동 상태와 `commonTest`
2. Android와 iOS TXT 문서 선택기
3. 적응형 CMP 읽기 화면
4. 검색, 위치와 입력 복원, CSV
5. 뷰어, 북마크, 표시 설정
6. 오프라인 사전과 사용자 선택형 온라인 보완

## 객체지향 주의

- Flutter `ReadScreen`은 UI, 파일 I/O, 번역, 타이머와 상태를 함께 다뤄 단일 책임 원칙을 위반한다.
- Android 프로토타입 `ReadViewModel`은 파일, 저장, 검색, 번역, quota, 뷰어와 내보내기를 함께 다뤄 단일 책임 원칙을 위반한다.
- 두 구현 모두 화면 상태가 구체 저장소와 네트워크 구현에 직접 의존해 의존성 역전 원칙을 위반한다.
- CMP/KMP에서는 첫 슬라이스에 필요한 순수 상태, 플랫폼 파일 선택, 공통 UI만 분리하고 미사용 계층은 만들지 않는다.
