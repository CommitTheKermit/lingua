Lingua 개인정보처리방침

시행일: 2026년 9월 23일

Lingua는 영어 텍스트 읽기와 번역 학습을 돕는 앱입니다. 불러온 문서와 사용자가 작성한 번역문은 기본적으로 기기 안에 저장됩니다.

처리하는 정보

  • 읽기 화면의 번역 영역이 켜져 있을 때 표시되는 현재 문장
  • 온라인 번역 사용량을 관리하기 위한 Firebase 익명 사용자 식별자
  • 비정상 요청을 막기 위한 Firebase App Check 검증 정보와 기본 서비스 로그

문서 전체를 한 번에 전송하지는 않지만, 번역 영역이 켜진 상태에서 읽은 문장은 각각 자동으로 전송됩니다. 문서의 모든 문장을 읽으면 결과적으로 문서 전체 내용이 문장별로 전송될 수 있습니다. 직접 작성한 번역문은 전송하지 않습니다. 번역 영역을 끄면 새 문장 번역 요청을 시작하지 않습니다.

이용 목적과 처리 방식

온라인 번역 요청은 암호화된 연결을 통해 Google Firebase Cloud Functions로 전달되며, 번역 결과를 만들기 위해 DeepL에 전송됩니다. Firebase에는 월별 사용량, 중복 요청 방지를 위한 번역 캐시, 서비스 보호에 필요한 기록이 저장될 수 있습니다.

제3자 서비스

  • Google Firebase 개인정보 보호 및 보안
  • DeepL 개인정보처리방침

Lingua는 사용자 정보를 판매하지 않으며 광고에 사용하지 않습니다.

보관과 삭제

기기 안의 문서와 번역문은 사용자가 앱 데이터를 삭제하거나 앱을 제거할 때 삭제됩니다. 서버의 사용량 기록과 번역 캐시는 서비스 운영, 비용 관리, 부정 이용 방지를 위해 필요한 기간 동안 보관됩니다. 서버 데이터 삭제를 요청하려면 아래 이메일로 문의해 주세요.
